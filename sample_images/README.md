These are generated, deterministic geometric test fixtures, not real camera photographs. ground_truth.json contains page corners. Run python tools/generate_samples.py to reproduce. A partial-page image is a stress case; missing text cannot be recovered. Large input is generated in tests rather than stored. Also test your own phone photographs before evaluation.

ocr_test_page.png and ocr_expected.txt are a known printed-text fixture generated by tools/evaluate_optionals.py. Their OCR error measurements apply only to that clean English fixture.
